## [cite_start]Опис класів [cite: 15]

### `MatrixUtils`

Клас-модель для роботи з матрицями типу `long`. Містить:

| Метод | Тип | Опис |
|-------|-----|------|
| `MatrixUtils(long[][] data)` | Constructor | Створює об'єкт матриці на основі двомірного масиву з глибоким копіюванням |
| `random(rows, cols, min, max)` | `static` | Фабричний метод для генерації матриці зі випадковими значеннями |
| `transpose()` | Instance | Повертає новий об'єкт `MatrixUtils`, який є транспонованою матрицею ($C = B^T$) |
| `calculateSpecialSum()` | Instance | Обчислює та повертає суму максимумів парних стовпців та мінімумів непарних стовпців |
| `print()` | Instance | Виводить матрицю у консоль у форматованому вигляді |
| `get(row, col)` | Instance | Повертає значення елемента за вказаними індексами |
| `getRows()` / `getCols()` | Instance | Повертають відповідну кількість рядків або стовпців матриці |

### `Matrix`

[cite_start]Виконавчий клас, що містить метод `main`[cite: 15, 17]. [cite_start]Задає початкові параметри, викликає методи класу `MatrixUtils` та забезпечує обробку виключних ситуацій за допомогою блоків `try-catch`[cite: 16, 17].
